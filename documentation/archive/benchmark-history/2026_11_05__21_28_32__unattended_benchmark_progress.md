# Unattended benchmark implementation and blocker

`benchmarks/api_sync/container_eval.py` implements a fail-closed Docker executor with a separate read-only candidate-and-suite mount, no network, no capabilities, non-root user, limited memory/CPUs/processes and a timeout. The public stage receives no hidden suite; the hidden stage receives only the final candidate. A basic probe checks non-root execution, no Docker socket, and blocked outbound network before testing. These settings reduce exposure but are not proof of a complete security boundary; they have not been exercised against a real Docker engine on this computer.

`benchmarks/api_sync/unattended_benchmark.py` implements a bounded, local llama.cpp generation/public-test-feedback loop with up to three repairs, hidden final validation, raw artifacts, resource sampling, a watchdog, and optional deletion of completed GGUF runs restricted to `benchmarks/api_sync/model-downloads/`. It owns and stops its local model-server process. It does not download model files or install llama.cpp; those remain prerequisites. End-to-end execution and model cleanup are unverified on this computer.

Six unit tests for missing Docker, simulated container timeout cleanup, isolation probe failure, blocked runner/no deletion, streamed response and low-memory stop passed on 2026-11-05. These simulations are not an actual sandbox validation. A real preflight and attempted benchmark stopped before inference with `Docker is not installed or is not on PATH`; no model was downloaded or run and no generated code was executed. WSL also reports it is not installed, and Windows Sandbox was not found. The machine is Windows 11 Home.

Next prerequisites are a functioning Linux container engine, creation of the benchmark image from the project Dockerfile, a successful isolation probe and reference-suite run inside it, then a compatible llama.cpp build and one model with checked disk/RAM headroom. The user must authorize any security-sensitive Windows feature change; WSL setup commonly requires administrator privileges and restart. Do not bypass the isolation gate or silently substitute a host venv.
