# Benchmark evidence audit

The specification, design, task list, public skeleton, public tests, and hidden tests match `benchmarks/api_sync/input_hashes.sha256`. The reference in `src/sync_app.py` was rerun in Python 3.12.10 with the network guard: 39 tests passed and line coverage was 98.17%. The tests use mocked HTTP or injected fetchers, mock/injected sleeps, and temporary or in-memory databases. The test suite provides evidence of its assertions, not proof that every production failure mode has been covered.

Three separate chat-v3 run directories contain each model's prompts, responses, candidates, public-check results, final hidden-check results, call counts, elapsed time and review counts; see `2026_11_05__02_13_45__api_sync_chat_v3_results.md`. No model passed both gates, so the available timings are unsuccessful-run durations, not time to a working project. The recommendation remains provisional; the open goal of establishing a demonstrated successful fallback is not met.

The benchmark test dependencies used here are now recorded in `benchmarks/api_sync/requirements.txt`, and the README includes the network-guarded reference verification command. Earlier reports and outputs remain preserved. A useful next experiment is a separately labeled, equally bounded repair protocol that asks for small reviewed patches rather than regenerating the entire file; it would need new runs for all candidates and must keep hidden results out of prompts. This is a proposed experiment, not an existing result.
